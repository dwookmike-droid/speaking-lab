# 학생 개인정보 운영 수칙 (선생님용)

## 등록
1. `python3 tools/cloud_sync.py invite`로 학생 번호와 등록 코드를 만들어 학생에게 줘요(14일, 1회용).
2. 학생이 앱에서 정보 입력과 동의를 마치면 동의 기록이 서버에 남고, `cloud_sync.py pull`이 명단에 옮겨요.
3. `python3 tools/intake.py <zip>`이 `students/roster.yaml`에 학생 번호를 붙여 적어요(동의 기록이 없으면 받지 않아요). 14세 미만이면 보호자 동의 확인 방법(문자/서명)과 날짜를 같이 적어요. 종이 서명은 사진을 찍어 `students/<번호>/consent/`에 둬요.

## 피드백 작업
- Claude에 넣는 파일에는 **학생 번호만** 써요. 이름·연락처·이메일은 넣지 않아요.
- Claude 계정 설정에서 대화 내용이 모델 학습에 쓰이지 않게 꺼 둬요. 설정 이름은 바뀔 수 있으니 분기마다 한 번 확인해요.
- 녹음 원본은 Claude에 올리지 않아요. 전사본만 써요.

## 보관과 삭제
- `students/`, `submissions/`는 git에 올리지 않아요(`.gitignore`).
- 메신저로 받은 제출 파일은 컴퓨터에 옮긴 뒤 메신저 대화방에서 지워요.
- 수업이 끝나면 `roster.yaml`에 종료일을 적고, 보유 기간이 지나면 `cloud_sync.py delete S00N`으로 서버 자료도 지워요.
- 매달 `python3 tools/purge.py`로 보유 기간(종료 후 3개월)이 지난 학생을 찾아 녹음·전사본·피드백·명단을 지워요.
- 학생이 앱에서 동의를 철회하면 서버 자료는 바로 지워지고 `cloud_sync.py pull`이 알려 줘요. 그때(또는 zip 방식에서 `speaking-lab_withdrawal_*.json`이 오면) `python3 tools/purge.py --student S00N --now --apply`와 `cloud_sync.py delete S00N`으로 바로 지워요. 명단에는 번호와 날짜만 남아요.

## 동의서를 고칠 때
- 원본 `content/legal/consent_vN.yaml`을 새 버전 파일로 만들고 `consent_version`을 올린 뒤 `python3 tools/build.py`를 돌려요. 앱은 다음 접속 때 학생에게 다시 동의를 받아요.
- 예전 버전 파일은 지우지 않아요. 누가 어느 버전에 동의했는지 확인할 때 써요.

## 서버 계정
- 선생님 도구는 선생님 계정 이메일·비밀번호를 환경변수(`SL_TEACHER_EMAIL`, `SL_TEACHER_PASSWORD`)로만 받아요. 파일이나 리포에 적지 않아요.
- Supabase 관리자 키(service_role)는 Speaking Lab 어디에도 쓰지 않아요.
